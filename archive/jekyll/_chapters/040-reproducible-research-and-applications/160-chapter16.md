abstract: >
    AI assistants have changed how researchers learn and write R. This chapter shows how to use tools such as ChatGPT, Claude, and GitHub Copilot to write, explain, and debug R code, and how to verify what they produce. It then introduces calling language models directly from R with the ellmer package to classify text and code open-ended survey responses, and closes with responsible use: data privacy, reproducibility, and disclosing AI use in publications.
