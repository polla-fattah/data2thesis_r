The playground is where you practise. Every chapter of the book has a playground page with exercises on Elaf's data. There are two ways to do them:

- **In your browser.** Type and run R code right on the page. You do not need to install anything.
- **On your own computer.** Download the chapter's project and open it in RStudio. It contains the data, the exercises, and the solutions.

Try each exercise yourself before you open the solution. Making mistakes and fixing them is how everyone learns R.
