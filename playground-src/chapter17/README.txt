From Data to Thesis: Research Data Analysis with R
Playground, Chapter 17: Using AI with R

How to use this project
1. Double-click chapter17.Rproj. RStudio opens with this folder as the working directory.
2. Open exercises.R and work through the exercises. Run a line with Ctrl+Enter.
3. Check your answers in solutions.R, after you have tried each exercise yourself.

The exercises need these packages (install once):
install.packages(c("dplyr", "stringr", "yardstick", "ellmer", "usethis"))

Exercises 1 to 4 need nothing else. Exercises 5 and 6 call a language model.
The chapter uses a free local model, which needs no key and keeps the data on
your computer:
- Install Ollama from ollama.com, then run this once in a terminal:
    ollama pull gemma4:e4b
  (a download of about 10 GB; a computer with a graphics card is much faster).
Or use an online model: set use_local <- FALSE in the scripts, create an API key
with a provider (for example Anthropic), run usethis::edit_r_environ(), add a
line such as ANTHROPIC_API_KEY=your-key, save, and restart R. Never put a key
in a script. Real research data may only be sent to an online service if your
ethics approval allows it.

Files
- exercises.R               the exercises, with starter code
- solutions.R               one possible solution for each exercise
- students.csv              one row per student in Elaf's study (600 students)
- open_responses.csv        the students' answers to the open question
- open_responses_coded.csv  200 answers hand-coded by Elaf into seven themes

Please note: Elaf and her data are fictional. The data was generated by a
computer program to look realistic, and its patterns were built in by the
author. It describes no real people and is not evidence about real students;
do not cite or use it as research findings.
