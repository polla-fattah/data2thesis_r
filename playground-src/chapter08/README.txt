From Data to Thesis: Research Data Analysis with R
Playground, Chapter 8: Multivariate Statistical Methods

How to use this project
1. Double-click chapter08.Rproj. RStudio opens with this folder as the working directory.
2. Open exercises.R and work through the exercises. Run a line with Ctrl+Enter.
3. Check your answers in solutions.R, after you have tried each exercise yourself.

The exercises need these packages (install once):
install.packages(c("dplyr", "psych", "GPArotation", "factoextra"))

Files
- exercises.R        the exercises, with starter code
- solutions.R        one possible solution for each exercise
- semesters.csv      one row per student per semester
- questionnaire.csv  the 22 questionnaire items

Please note: Elaf and her data are fictional. The data was generated by a
computer program to look realistic, and its patterns were built in by the
author. It describes no real people and is not evidence about real students;
do not cite or use it as research findings.
Exercises 1 to 5 can also be done in your browser at:
