From Data to Thesis: Research Data Analysis with R
Playground, Chapter 2: Data Structures in R

How to use this project
1. Double-click chapter02.Rproj. RStudio opens with this folder as the working directory.
2. Open exercises.R and work through the exercises. Run a line with Ctrl+Enter.
3. Check your answers in solutions.R, after you have tried each exercise yourself.

Exercise 9 reads the SPSS file and needs the haven package:
install.packages("haven")

Files
- exercises.R         the exercises, with starter code
- solutions.R         one possible solution for each exercise
- students.csv        one row per student in Elaf's study (600 students)
- semesters.csv       one row per student per semester
- wellbeing_raw.xlsx  the messy survey export (cleaned in Chapter 3)
- wellbeing.sav       the SPSS version of the data, with labels

The data is simulated for teaching and describes no real people.
The same exercises (except the SPSS one) can be done in your browser at:
https://polla-fattah.github.io/R4NTR/playground/chapter02.html
