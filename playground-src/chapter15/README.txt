From Data to Thesis: Research Data Analysis with R
Playground, Chapter 15: Time Series Forecasting

How to use this project
1. Double-click chapter15.Rproj. RStudio opens with this folder as the working directory.
2. Open exercises.R and work through the exercises. Run a line with Ctrl+Enter.
3. Check your answers in solutions.R, after you have tried each exercise yourself.

The exercises need these packages (install once):
install.packages(c("dplyr", "ggplot2", "tsibble", "fable", "feasts", "urca"))

Files
- exercises.R        the exercises, with starter code
- solutions.R        one possible solution for each exercise
- counselling_visits.csv  weekly visits to the counselling service, 2020 to 2025

The data is simulated for teaching and describes no real people.
Base R versions of the main ideas can be tried in your browser at:
https://polla-fattah.github.io/R4NTR/playground/chapter15.html
