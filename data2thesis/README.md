# data2thesis

Data for the book *From Data to Thesis: Research Data Analysis with R*: the **Graduate Wellbeing Study**, the book's running case study.

Elaf, a Master's student in Educational Psychology, follows 600 graduate students over four semesters to learn how lifestyle, stress, and supervisor support relate to their wellbeing, grades, and thoughts of dropping out, and whether a wellbeing workshop helps. The data is simulated for teaching and describes no real people.

## Installing

Choose one of these. Both install the same package.

**From the book's website** (needs nothing else):

```r
install.packages("https://polla-fattah.github.io/R4NTR/data/data2thesis_1.0.0.tar.gz",
                 repos = NULL, type = "source")
```

**From GitHub** (needs the `remotes` package):

```r
install.packages("remotes")
remotes::install_github("polla-fattah/R4NTR", subdir = "data2thesis")
```

## Using

```r
library(data2thesis)

head(students)          # background, workshop group, dropout question
head(questionnaire)     # 22 questionnaire items
head(semesters)         # semester records, one row per student per semester
head(supervisors)
head(open_responses)    # open-ended answers
head(counselling_visits)

?students               # help page for each dataset
```

The raw files are included for practising data import:

```r
data2thesis_example()                                    # list the files
read.csv(data2thesis_example("students.csv"))
readxl::read_excel(data2thesis_example("wellbeing_raw.xlsx"))   # the messy survey export
haven::read_sav(data2thesis_example("wellbeing.sav"))           # SPSS file with labels
```

## The same data as files

Every dataset is also available as a file in the [`data/`](../data) folder of the book's repository and website.

## How the data was made

The data is generated by [`data-raw/generate_wellbeing.R`](../data-raw/generate_wellbeing.R) from a fixed seed, and [`data-raw/check_wellbeing.R`](../data-raw/check_wellbeing.R) confirms every effect described in the [specification](../data/specification.md). To update the package after regenerating the data, run `Rscript data-raw/build_package.R`.
